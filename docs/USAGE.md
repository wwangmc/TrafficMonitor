# 使用说明

## 开始使用

1. 手机安装TrafficMonitor，保持越狱与ElleKit有效，USB连接并信任电脑。电脑实时读取要求手机已有MKS/roothelp通道可用。
2. Windows双击根目录start.cmd，或直接打开已经运行的 http://127.0.0.1:27681/ 。首次启动需要Python3.9+及tidevice，启动器自动安装依赖。无需访问令牌或登录。
3. 从「监控应用」下拉框选择一个应用，配置自动保存。请完全结束并重新打开新选应用，随后请求自动出现。

界面保留应用选择、按请求/按域名切换及删除记录。请求视图只有两列：请求URL、大小。每秒更新所选应用最近200条记录，按大小从大到小排序，未知大小最后显示。长URL以单行显示，悬停可查看完整值，选中文字可复制；参数值已脱敏。

大小是请求body与响应应用数据的合计，任一项无法确定时显示「未知」。不包含HTTP报头、TCP/IP报头或重传，也不与Socket统计混合。后台继续保存采集记录，沿用已有保留期限（默认7天、每类最多100000条）。

## 按域名汇总与删除

点击「按域名」，对当前应用全部已保存请求按URL主机名汇总，子域名单独统计，不受请求列表最近200条限制；按已知总大小降序显示最多200个域名。汇总含未知大小时显示「≥ 已知合计」，全未知时显示「未知」，不会把未知部分假装成0。悬停大小可查看请求数量和未知条数。

「删除记录」弹出确认，确认后只删除当前应用的HTTP、Socket及相关游标/健康记录，并通过USB清理该应用自己的四个采集日志文件；不清理其他应用的历史或手机日志。旧记录不会因轮转日志重新读取而恢复；删除后新产生的请求仍继续显示。操作不可恢复，删除前请自行备份需要保留的历史。

## 连接与运行

服务只监听127.0.0.1:27681并保留Host/Origin检查，浏览器与本机工具直接访问。启动窗口需保持运行，Ctrl+C退出。服务重启后刷新页面即可。多设备手动运行时使用 --udid；仅查看本地历史可用 --offline。

切换应用后旧进程通过USB配置停止采集，新选应用冷启动后开始采集。配置失败会重试；出现错误时界面显示读取错误，已存请求仍可查看。断线超过手机日志轮转容量可能丢失尚未同步的历史。

SQLite位于desktop/data/trafficmonitor.sqlite3，不上传仓库。退出服务后可复制整个desktop/data目录备份。卸载手机包后需完全结束监控应用，手机tmp/TrafficMonitor与电脑历史独立存在。不要删除整个应用容器。

当前界面不展示速度曲线、Socket会话、IP汇总、详情弹框或独立设置面板；域名汇总和当前应用删除直接放在列表工具栏。
